# 📂 Python File Organizer

A clean, modular Python automation script to declutter messy directories by sorting files into categorized folders based on their extensions.

---

## ✨ Features
- Automatically categorizes files into **Images**, **Documents**, **Archives**, **Media**, and **Code**.
- Safe handling: Ignores the script file itself to avoid self-movement.
- Groups unrecognized formats cleanly into an **Others** directory.
- Built using native standard libraries (`pathlib`, `shutil`) — zero extra dependencies needed.

---

## 🛠 Tech Stack
- **Language:** Python 3.8+
- **Standard Libraries:** `os`, `shutil`, `pathlib`
